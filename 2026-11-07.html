1. Claude Code 2.1.319: strakkere auto mode en MCP-taken op de achtergrond

Auto mode valt niet meer terug op de ingebouwde classifier als telemetrie of feature flags ontbreken. Aanroepen die de server niet kan controleren, worden dan gevraagd of geweigerd. Wil je het oude gedrag, zet dan CLAUDE_CODE_AUTO_MODE_SERVER=0.

Een taak die een MCP-server draait, gaat in de terminal meteen naar de achtergrond. Claude krijgt het resultaat als de taak klaar is. Nieuw is ook de setting permissions.denyInsteadOfPrompting, die tool calls weigert in plaats van op een prompt te wachten, en CLAUDE_CODE_DISABLE_FEATURE_FLAGS, die flags stopt zonder telemetrie uit te zetten.

Probeer: gebruik je Claude Code in CI of headless, zet dan permissions.denyInsteadOfPrompting aan. Een job blijft dan niet hangen op een prompt die niemand ziet. Heb je MCP-servers met langlopende taken, test dan of de nieuwe achtergrondafhandeling past. Zo niet, dan zet CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND het oude gedrag terug.

2. Claude API-versie 2026-10-21 en SDK's met breaking changes

Op 21 oktober kwam er een nieuwe API-versie, met een migratiegids en nieuwe SDK-releases: Python 2.0.0, TypeScript 1.0.0 en ant CLI 2.0.0. Deze versies bevatten breaking changes. De licentie is ook veranderd van MIT naar Apache 2.0. Dit stond nog niet in eerdere digests en valt makkelijk te missen als je dependencies niet vastzet.

Probeer: check in je Django- en Next.js-backends welke versie van de Anthropic SDK je gepind hebt. Upgrade op een branch, lees eerst de migratiegids en draai je tests tegen de nieuwe versie voordat je een range als ^1 of >=1 laat oppakken.

Claude Platform release notes

3. Usage and Cost Analytics API (beta)

Sinds 29 oktober zijn er endpoints onder /v1/organizations/analytics/usage en /cost. Je zet ze aan met de header analytics-usage-cost-2026-08-24. Je kunt filteren en groeperen op model, workspace, API-key en gebruiker of service account. De oude Usage and Cost API en de report-endpoints van de Enterprise Analytics API zijn nu legacy. Ze blijven werken.

Probeer: als je per klant of per project een eigen API-key of workspace gebruikt, kun je hiermee kosten per RAG- of agent-backend uitrekenen zonder eigen logging. Vergelijk de cijfers eens met wat je zelf bijhoudt.

Claude Platform release notes

4. Gemini 4 Argon en een API-CLI voor coding agents

Volgens de Gemini API changelog is gemini-4-argon algemeen beschikbaar, als het sterkste model van Google voor complexe code, agents, wiskunde en wetenschap. De exacte datum is onduidelijk: ik zag zowel 13 als 26 oktober. Op 27 oktober volgde een beta van de Gemini API CLI, een stateless client zonder dependencies voor coding agents, scripts en CI. Ik heb prijzen en benchmarks niet kunnen controleren.

Probeer: vooral de CLI is interessant als je agents in Docker of CI hebt die een tweede model nodig hebben. Lees eerst de changelog voor prijs en limieten voordat je het in een pipeline zet.
