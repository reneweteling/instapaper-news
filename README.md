# instapaper-news

Dagelijkse Nederlandstalige AI-digest, gepubliceerd via GitHub Pages zodat Instapaper er een URL-artikel van maakt (en het naar de Kobo synct).

- `YYYY-MM-DD.html` — één digest per dag (`<title>` = onderwerpregel, `lang="nl"`, geen afbeeldingen)
- `index.html` — archief, gegenereerd met `python3 build_index.py`
- Live: https://reneweteling.github.io/instapaper-news/
